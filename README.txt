РЕАЛЬНЫЕ ЗАКАЗЫ:
GitHub Pages сам заявки не хранит. Используется Google Sheets + Apps Script.
1) Создай Google Таблицу.
2) Extensions -> Apps Script.
3) Вставь google-apps-script.js.
4) Deploy -> New deployment -> Web app -> Execute as Me -> Anyone.
5) Скопируй URL /exec.
6) В config.js: window.ORDER_ENDPOINT='ТВОЙ_URL';
7) Залей config.js в GitHub.
После этого заявки из формы попадут в твою таблицу.
